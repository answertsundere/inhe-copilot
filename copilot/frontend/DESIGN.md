# INHE 客服知识库 Copilot — 设计系统

> Category: Admin Dashboard / Knowledge Base
> 客服知识库后台管理系统。温暖极简 + 精密深色侧边栏，适配中文阅读。

## 1. 视觉主题与氛围

INHE 客服知识库 Copilot 是一个面向客服专员、主管和管理员的知识管理后台。设计目标是让大量信息清晰可扫、长时间使用不易疲劳、操作反馈明确。

整体采用 **浅色主内容区 + 深色侧边导航** 的混合布局：
- 侧边栏使用深色精密风格（参考 Linear），让导航在视觉上稳定、不抢戏
- 主内容区使用温暖极简风格（参考 Notion），大面积留白、柔和边框、清晰层级
- 中文为主，因此不使用极端负字间距，保持阅读舒适度

**核心特征：**
- 主背景：暖白色 `#fafafa`，替代 Element Plus 默认冷灰 `#f5f7fa`
- 侧边栏：近黑深蓝 `#12131a`，营造稳定导航锚点
- 主强调色：品牌靛蓝 `#4f6af6`，用于主按钮、选中态、链接
- 边框系统：极细半透明黑边 `rgba(0,0,0,0.08)`，轻盈分隔
- 阴影系统：低透明度多层阴影，模拟轻微纸张抬升
- 字体：系统字体栈优先，中文使用 `"PingFang SC", "Microsoft YaHei"`
- 圆角：6px 功能元素 / 8px 卡片 / 12px 大面板

## 2. 色彩体系

### 背景色
- **页面背景** `#fafafa`：主内容区背景
- **卡片背景** `#ffffff`：纯白卡片表面
- **侧边栏背景** `#12131a`：深色导航背景
- **侧边栏二级表面** `#1a1c26`：侧边栏 hover / 分组背景
- **悬浮表面** `#f3f4f6`：hover、浅灰按钮背景

### 文字色
- **主文字** `rgba(0,0,0,0.9)`：标题、正文
- **次文字** `rgba(0,0,0,0.55)`：说明、描述
- **辅助文字** `rgba(0,0,0,0.35)`：占位、时间戳、禁用
- **侧边栏主文字** `rgba(255,255,255,0.85)`：导航默认
- **侧边栏次文字** `rgba(255,255,255,0.5)`：未激活、辅助

### 品牌与强调
- **品牌靛蓝** `#4f6af6`：主按钮、链接、选中态
- **品牌悬停** `#3d56d6`：按钮 hover
- **品牌浅底** `#eef1ff`：标签、徽章背景

### 状态色
- **成功** `#16a34a` / 浅底 `#dcfce7`
- **警告** `#d97706` / 浅底 `#fef3c7`
- **危险** `#dc2626` / 浅底 `#fee2e2`
- **信息** `#0ea5e9` / 浅底 `#e0f2fe`

### 边框与分隔
- **浅色边框** `rgba(0,0,0,0.08)`：卡片、输入框、分隔线
- **深色边框** `rgba(255,255,255,0.08)`：侧边栏内分隔

## 3. 字体规范

### 字体栈
- **主字体**：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Helvetica Neue", Helvetica, Arial, sans-serif`
- **等宽字体**：`ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, monospace`

### 层级（适配中文）

| 角色 | 字号 | 字重 | 行高 | 字间距 | 用途 |
|------|------|------|------|--------|------|
| 页面大标题 | 24px | 600 | 1.35 | 0 | 页面顶部标题 |
| 卡片标题 | 18px | 600 | 1.4 | 0 | 卡片/面板标题 |
| 小标题 | 16px | 600 | 1.5 | 0 | 表单组标题、分组 |
| 正文 | 14px | 400 | 1.6 | 0 | 主要阅读文字 |
| 正文强调 | 14px | 500 | 1.6 | 0 | 表格关键字段 |
| 辅助文字 | 13px | 400 | 1.5 | 0 | 说明、元信息 |
| 小标签 | 12px | 500 | 1.4 | 0.2px | 状态标签、徽章 |
| 导航项 | 14px | 500 | 1.4 | 0 | 侧边栏菜单 |

### 中文适配原则
- 不使用极端负字间距，中文笔画复杂，过紧会降低辨识度
- 行高保持 1.5–1.6，给 CJK 字符留呼吸空间
- 标题字重最高 600，避免过粗的宋体/黑体堆叠感
- 最小可读字号 12px，不滥用 10px 微型文字

## 5. 布局原则

### 间距系统
- 基础单位：8px
- 常用值：4px, 8px, 12px, 16px, 20px, 24px, 32px, 48px
- 卡片间距：16px
- 页面内边距：24px

### 布局结构
- 侧边栏宽度：220px
- 顶部标题栏高度：56px
- 内容最大宽度：无限制，但卡片栅格建议 1200px
- 卡片栅格：1–4 列，gap 16px

### 空白哲学
- 信息密集后台不需要 Awwwards 式超大留白
- 用 16–24px 的清晰间距分组，避免元素粘连
- 卡片作为信息容器，内部紧凑，外部留足呼吸

## 6. 深度与层级

| 层级 | 处理 | 用途 |
|------|------|------|
| 0 页背景 | `#fafafa`，无阴影 | 页面底层 |
| 1 卡片 | 白底 + 细边框 + 微阴影 | 标准卡片 |
| 2 悬浮 | hover 阴影增强 | 可交互卡片 |
| 3 下拉/弹窗 | 多层阴影 + 边框 | 下拉菜单、对话框 |
| 4 侧边栏 | 深色固定 | 始终在最顶层视觉锚点 |

## 7. 该做与不该做

### 该做
- 使用 `#fafafa` 替代 Element Plus 默认冷灰背景
- 使用 `rgba(0,0,0,0.08)` 细边框分隔卡片
- 保持侧边栏深色稳定，主内容区浅色清爽
- 用品牌靛蓝 `#4f6af6` 统一所有主交互色
- 状态色统一使用语义化浅底深字徽章
- 表格、表单边距保持 16–20px 舒适区

### 不该做
- 不要引入多种强调色（橙、紫、粉混用）
- 不要使用纯黑 `#000000` 作为主文字
- 不要在侧边栏使用高饱和彩色图标
- 不要给每个卡片加厚重阴影
- 不要使用小于 12px 的字号展示关键信息
- 不要让按钮、标签、链接使用不同颜色体系

## 8. 响应式

- 桌面（>1024px）：完整侧边栏 + 主内容区
- 平板（768–1024px）：侧边栏可收起为图标模式
- 移动端（<768px）：侧边栏变为抽屉，内容单列堆叠
