📖 零配置模式说明

当前运行在无 AI 模式（规则引擎） — 系统未配置 LLM API Key，所有回复由规则引擎生成。

什么是零配置模式？
当未配置 COPILOT_LLM_API_KEY 时，系统会自动降级到规则引擎模式。此模式下：
• 消息分析通过关键词匹配识别意图（ shipping / 退款 / 质量 / 投诉 等）
• 建议回复从 840 条话术模板中匹配最佳回复
• 安全策略通过规则引擎检查（禁止承诺、线下交易、粗鲁用语）
• 提供订单号时，系统会根据订单真实状态生成针对性回复（如"您的订单已发货，单号是 xxx"）
• 高风险消息自动进入人工复核队列

如何启用 AI 模式？
在 copilot/.env 文件中添加：
COPILOT_LLM_API_KEY=your_api_key_here
然后重启服务器即可。
